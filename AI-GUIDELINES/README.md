# AI Guidelines

This directory contains project-local instructions for AI harnesses.

`AGENT.md` is the shared source of guidance. It is not loaded automatically: mention `AI-GUIDELINES/AGENT.md` in each prompt that should use it.

`copy-writer-helper.md` is the source for portfolio copy. Mention it explicitly for copywriting or text-content changes.

`README.md` and `PRD.md` remain in the repository root because they document the application rather than agent behavior.

No project-local skills are defined yet. Add a skill only when it has a concrete, reusable workflow; store it at `AI-GUIDELINES/skills/<name>/SKILL.md` and mention it explicitly.
